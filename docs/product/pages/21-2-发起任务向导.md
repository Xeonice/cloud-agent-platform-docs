# P21-2 · 发起任务向导

当前页面说明。[LCH 完整需求与验收](../requirements/LCH.md) · [AUTH 完整需求与验收](../requirements/AUTH.md) · [SBX 完整需求与验收](../requirements/SBX.md) 定义当前产品行为与验收条件。

## 1. 页面目标

在同一个表单搜索并选择已有项目、分支和镜像，指定 Agent 与任务指令；凭证不足时原位配置，成功后继续原表单。项目、分支、镜像统一采用 shadcn 可搜索单选 Combobox（REQ-LCH-018），键入搜索不创建对象。

## 2. 进入方式

新建任务弹层；`/?new=1&project=<项目 id>` 查询参数深链入口（REQ-LCH-009）。

## 3. 布局与信息层级

弹层标题与页脚固定，正文滚动；字段按项目 → Agent / 凭证闸门 → 分支（仅 Git 项目）→ 镜像 → 指令排列。可搜索选择器的触发器显示已选值，展开后顶部搜索框、下方可滚动候选项；宽度与触发器对齐。登录面板在 Agent 分组内展开，发起按钮始终可见。

镜像有别名时显示别名与真实坐标两行，真实坐标保持可辨；无别名回退真实坐标。分支默认项与预制镜像默认项固定在对应候选区顶部，不被搜索过滤；预制默认项保留「平台预制镜像（默认）」名称，辅助行可显示别名与真实坐标。

## 4. 组件与操作

| 字段 | 搜索提示 | 匹配范围 | 选择与默认行为 |
| --- | --- | --- | --- |
| 项目 | 搜索项目… | 已加载项目 name | 仅就绪项目可选；顺序同树、当前项目置顶；变更后重置分支与分支搜索词，Agent / 镜像 / 指令保留 |
| 分支 | 搜索分支… | 已加载完整分支 name，包含路径前缀 | 默认「跟随项目当前的分支（默认）」始终可见；空项目没有本字段 |
| 镜像 | 搜索镜像名称、别名或地址… | 已加载别名 / imageName / ref / tag | 默认入口始终可见；一张镜像一项，按既有真实绑定 / 坐标发起 |

搜索统一 trim、大小写不敏感的子串匹配，保留原相对顺序；不发远端搜索请求。缺凭证只展示折叠闸门，点配置才展开，点开始登录才启动后端会话。发起后显示阶段进度，失败保留最后阶段并提供有意义的出口。

## 5. 状态矩阵

项目 / Agent / 分支 / 镜像各自呈现加载与读取失败；读取失败、列表为空、搜索无匹配分别说明。搜索无匹配显示「没有匹配的项目 / 分支 / 镜像」，可清空搜索恢复；分支与预制镜像默认入口仍在，已选对象不变。

克隆中 / 失败的项目与禁用 / 无效镜像匹配后显示原原因并不可选；Provider 不兼容镜像不列，缺所选 Agent 的 CLI 仅警告仍可选。预制默认入口禁用时仍写原因，不能绕过禁用。未配置 / 已过期凭证阻止发起；即将过期给建议。创建中锁定全部字段与搜索浮层；取消、超时和失败分别处理。

## 6. 交互细节

展开选择器后聚焦搜索框；上下键移动到可选项，Enter 选择后关闭并回到触发器，Tab 按表单顺序继续。中文输入法组合过程的 Enter 只确认文字，不选择或提交；第一次 Esc 只关当前选择浮层、焦点回触发器，再次 Esc 才按任务弹层规则关闭。字段有可感知的标签、展开与选中状态。

搜索、清空或关闭不改变已选值；关闭后清空该字段查询，下次展开从完整列表开始。搜索词不进入 URL、请求或持久化存储；候选因筛选不可见时，触发器仍显示原已选对象。

新建项目入口位于工作台或项目总览，不嵌套进新任务弹层；任务指令在原位登录期间保留；服务端最终决定容量与资源是否可用。

## 7. 数据依赖

GET projects / runtimes / 项目本地分支 / images；镜像列表包含 `imageAlias: string | null` 与真实坐标、版本、可用性。POST sandboxes 沿用既有项目、分支与真实镜像标识 / 坐标字段，不提交别名或查询词；runtime auth begin/status/complete/cancel 与 secret；创建阶段事件。

## 8. 退出路径

选择浮层先独立关闭；任务弹层取消后回到原入口。创建中收起选择浮层、锁定输入与重复提交，并禁止关闭任务弹层；同步失败恢复原选择与指令，受理后关闭并转主区进度。

## 9. 边界规则

新建项目入口位于工作台或项目总览，不嵌套进新任务弹层；任务指令在原位登录期间保留；服务端最终决定容量与资源是否可用。

验收逐条使用 LCH、AUTH、SBX 的 AC，不继续使用旧页自编编号；代码、实跑记录与视觉证据分别登记。
