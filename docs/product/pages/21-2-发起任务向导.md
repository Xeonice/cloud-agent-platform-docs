# P21-2 · 发起任务向导

2026-10 设计迁移后的当前页面说明。[LCH 完整需求与验收](../../design-v2/gap/product/LCH.md) · [AUTH 完整需求与验收](../../design-v2/gap/product/AUTH.md) · [SBX 完整需求与验收](../../design-v2/gap/product/SBX.md) 是完整产品行为依据；原稿中的历史状态与待定问题不作为当前实现结论。

## 1. 页面目标

在同一个表单选择项目、Agent、任务指令与镜像；凭证不足时原位配置，成功后继续原表单。

## 2. 进入方式

新建任务弹层；`/new` 深链入口

## 3. 布局与信息层级

弹层标题与页脚固定，正文滚动；登录面板在 Agent 分组内展开。发起按钮始终可见；高级参数独立折叠，资源参数单位明确。

## 4. 组件与操作

选择可用项目与镜像；缺凭证只展示折叠闸门，点配置才展开，点开始登录才启动后端会话。发起后显示阶段进度，失败保留最后阶段并提供有意义的出口。

## 5. 状态矩阵

项目/Agent/镜像各自加载、失败、无可用项；未配置/已过期凭证阻止发起；即将过期给建议；创建中的进度不得伪造百分比；取消、超时和失败分别处理。

## 6. 交互细节

选择可用项目与镜像；缺凭证只展示折叠闸门，点配置才展开，点开始登录才启动后端会话。发起后显示阶段进度，失败保留最后阶段并提供有意义的出口。

新建项目入口位于工作台或项目总览，不嵌套进新任务弹层；任务指令在原位登录期间保留；服务端最终决定容量与资源是否可用。

## 7. 数据依赖

GET projects/runtimes/images；POST sandboxes；runtime auth begin/status/complete/cancel 与 secret；创建阶段事件。

## 8. 退出路径

取消关闭当前浮层并回到原对象；处理中锁定重复提交。跨页回程按所属领域要求清理，失败保留可重试出口。

## 9. 边界规则

新建项目入口位于工作台或项目总览，不嵌套进新任务弹层；任务指令在原位登录期间保留；服务端最终决定容量与资源是否可用。

验收逐条使用 LCH、AUTH、SBX 的 AC，不继续使用旧页自编编号；代码、实跑记录与视觉证据分别登记。
