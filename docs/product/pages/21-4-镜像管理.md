# P21-4 · 镜像管理

当前页面说明。[IMG 完整需求与验收](../requirements/IMG.md) 定义当前产品行为与验收条件。

## 1. 页面目标

管理预制镜像与自定义镜像版本，设置易辨认的别名并按别名或真实坐标查找；验证真实契约、启停可选性并如实说明引用与删除后果。

## 2. 进入方式

`/settings/images`

## 3. 布局与信息层级

页头后为搜索与状态过滤、镜像卡列表；预制镜像下载块保留原位置。卡头以别名为主标题、真实坐标为辅助行，没有别名时回退坐标；卡头提供独立 [编辑别名]。验证结果、版本与运行参数仍是各自区块，预制镜像不提供硬删除入口。

注册弹层在「镜像 URI」下方增加「别名 · 可选」、N/64 计数与说明「仅用于显示和搜索，不改变镜像地址」；打开时仍聚焦 URI。已有镜像的别名在卡头原位编辑，不嵌套镜像验证流程。

## 4. 组件与操作

搜索提示「搜索镜像名称、别名或地址…」，对已加载别名 / imageName / ref / tag 做 trim 后、大小写不敏感的子串匹配，和状态过滤取交集；不因输入发远端请求，保留原排序。

预制 / 自定义镜像都可点 [编辑别名]，展开单行输入、N/64、[保存别名] / [取消]。保存已有镜像别名不下载或重验；注册新镜像可同时填别名，注册已有镜像不得隐式改名，应定位到卡片独立编辑（REQ-IMG-060）。登记时解析并钉住 digest；校验 Entrypoint 或 Cmd、实际运行条件。下载有真实阶段和耗时，下载完成后执行真实诊断再收起；删除前读服务端引用，引用仍存在时保留禁用按钮及原因。

## 5. 状态矩阵

独立加载、空、失败状态；有镜像但搜索 / 过滤无匹配时显示原过滤空态，不能当成库里没有镜像。别名编辑分空闲、校验错误、保存中、保存失败、成功；错误与失败原位说明并保留草稿，成功收起并刷新已加载卡片与任务选择器。

验证成功 / 警告 / 失败分别显示；进行中为中性状态；未知进度为不定值条；失败保留最后阶段且不自动重试。

## 6. 交互细节

别名原输入先拒绝 Unicode Cc 控制字符与 U+2028 / U+2029，再 trim，最多 64 个 Unicode 码点；空白或 null 清除，省略字段保持原值，允许重复别名。错误框使用 aria-invalid 与关联原位错误；保存中锁定编辑器并防止重复提交。取消或空闲时 Esc 丢弃草稿、恢复原值、焦点回 [编辑别名]；成功按服务端返回值刷新且保留原搜索词，选择器的已选镜像身份不变。

卡片、选择器均保留真实坐标辅助显示；复制坐标复制真实坐标。注册表单只改别名不作废地址验证；重名的卡与候选用真实坐标区分。

停止/失败但未销毁任务仍可引用镜像；后端事务复查避免预览后的竞争；停用只影响新任务；镜像参数按版本保存，平台凭证由受控注入提供，不保存受限凭证变量。

## 7. 数据依赖

images CRUD、validate、activate、check-update、deletion-preview；别名请求使用可省略的 `alias: string | null`，响应使用 `imageAlias: string | null`。经版本行编辑入口查所属 Image 后更新共享别名，列表中所有版本回显一致；preset-image/provision SSE 与 system/diagnose SSE。

## 8. 退出路径

取消关闭当前浮层并回到原对象；处理中锁定重复提交。跨页回程按所属领域要求清理，失败保留可重试出口。

## 9. 边界规则

停止 / 失败但未销毁任务仍可引用镜像；后端事务复查避免预览后的竞争；停用只影响新任务。别名属于整张镜像、所有版本共享，更新 / 切换 / 回滚保留；运行参数按版本保存，平台凭证由受控注入提供，不保存受限凭证变量。

改名只影响显示与搜索，不改变 ref、digest、启用状态、验证结论、运行参数或已有任务绑定，任务诊断继续使用锁定的真实坐标与版本。

验收逐条使用 IMG 的 AC，不继续使用旧页自编编号；代码、实跑记录与视觉证据分别登记。

## 10. 运行参数体系

镜像版本保存环境变量与启动命令覆盖，任务锁定该配置并合并平台凭证注入。当前任务创建接口没有任务级环境变量或资源覆盖入口。验证 CPU 核数、RAM/disk 的 MB 单位、环境变量名与受限凭证变量；容量取实际 Provider 与平台模型，不覆盖用户已编辑的目标版本参数。Entrypoint 或 Cmd 可提供启动命令，WorkingDir 可默认 /。

## 11. 对契约与验收的要求

登记结果返回真实 digest、验证结论与 `imageAlias`；别名校验、归一和省略 / null 语义前后端一致，已有数据回填为 null。验收覆盖预制与自定义编辑、64 / 65 码点、非法字符、重名、各版本共享、重复注册不隐式改名、失败留草稿和成功同步视图（REQ-IMG-060、061）。

删除预览返回 actual 引用任务，删除事务再次校验。下载和诊断各使用实际 SSE，验收覆盖引用竞争、无百分比、完成后重检和失败留卡。
