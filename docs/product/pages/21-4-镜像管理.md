# P21-4 · 镜像管理

当前页面说明。[IMG 完整需求与验收](../requirements/IMG.md) 定义当前产品行为与验收条件。

## 1. 页面目标

管理预制镜像与自定义镜像版本，验证真实契约、启停可选性并如实说明引用与删除后果。

## 2. 进入方式

`/settings/images`

## 3. 布局与信息层级

预制镜像下载卡、镜像列表、验证结果和参数展开区；添加/验证/删除使用统一弹层。预制镜像不提供硬删除入口。

## 4. 组件与操作

登记时解析并钉住 digest；校验 Entrypoint 或 Cmd、实际运行条件。下载有真实阶段和耗时，下载完成后执行真实诊断再收起；删除前读服务端引用，引用仍存在时保留禁用按钮及原因。

## 5. 状态矩阵

独立加载、空、失败状态；验证成功/警告/失败分别显示；进行中为中性状态；未知进度为不定值条；失败保留最后阶段且不自动重试。

## 6. 交互细节

登记时解析并钉住 digest；校验 Entrypoint 或 Cmd、实际运行条件。下载有真实阶段和耗时，下载完成后执行真实诊断再收起；删除前读服务端引用，引用仍存在时保留禁用按钮及原因。

停止/失败但未销毁任务仍可引用镜像；后端事务复查避免预览后的竞争；停用只影响新任务；镜像参数按版本保存，平台凭证由受控注入提供，不保存受限凭证变量。

## 7. 数据依赖

images CRUD、validate、activate、check-update、deletion-preview；preset-image/provision SSE 与 system/diagnose SSE。

## 8. 退出路径

取消关闭当前浮层并回到原对象；处理中锁定重复提交。跨页回程按所属领域要求清理，失败保留可重试出口。

## 9. 边界规则

停止/失败但未销毁任务仍可引用镜像；后端事务复查避免预览后的竞争；停用只影响新任务；镜像参数按版本保存，平台凭证由受控注入提供，不保存受限凭证变量。

验收逐条使用 IMG 的 AC，不继续使用旧页自编编号；代码、实跑记录与视觉证据分别登记。

## 10. 运行参数体系

镜像版本保存环境变量与启动命令覆盖，任务锁定该配置并合并平台凭证注入。当前任务创建接口没有任务级环境变量或资源覆盖入口。验证 CPU 核数、RAM/disk 的 MB 单位、环境变量名与受限凭证变量；容量取实际 Provider 与平台模型，不覆盖用户已编辑的目标版本参数。Entrypoint 或 Cmd 可提供启动命令，WorkingDir 可默认 /。

## 11. 对契约与验收的要求

登记结果返回真实 digest 与验证结论；删除预览返回 actual 引用任务，删除事务再次校验。下载和诊断各使用实际 SSE，验收覆盖引用竞争、无百分比、完成后重检和失败留卡。
