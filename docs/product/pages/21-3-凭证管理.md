# P21-3 · 凭证管理

当前页面说明。[CRD 完整需求与验收](../requirements/CRD.md) · [AUTH 完整需求与验收](../requirements/AUTH.md) 定义当前产品行为与验收条件。

## 1. 页面目标

分别管理 Agent 的帐号登录/API Key 与平台 Git 凭证。显示打码标识、有效期、实际生效方式与删除后果。

## 2. 进入方式

`/settings/credentials`；Git 回程 `?section=git`

## 3. 布局与信息层级

设置主区左侧留白 32px、表单内容宽度 768px；Agent 卡头 56px、方式行至少 64px；登录面板位于卡片最后一行。Git 卡显示四行 metadata 与缺失类型入口。

## 4. 组件与操作

按 Agent 独立单选分组。切换已配置方式先确认，确认前徽标与单选不动；未配置方式原位补配。删除先读取真实凭证绑定，统一框按后果顺序展示，默认焦点取消。

## 5. 状态矩阵

两个分区独立骨架与错误重试；搜索只匹配名字和已显示的打码片段；读取失败不当作未配置。过期/即将过期显示下一步；未知删除清单明确可重试。

## 6. 交互细节

按 Agent 独立单选分组。切换已配置方式先确认，确认前徽标与单选不动；未配置方式原位补配。删除先读取真实凭证绑定，统一框按后果顺序展示，默认焦点取消。

Agent 删除按实际注入绑定销毁任务，准备中任务在注入前重新核对；同方式重新登录迁移绑定、不销毁任务。Git 凭证仅平台克隆/拉取使用，不注入 Agent；无真实目标仓库时不发送 secret。

## 7. 数据依赖

runtimes、credentials、auth-mode；runtime credential deletion-preview/DELETE；Git 保存、测试、删除；项目仓库列表用于测试目标与相关项目展示。

## 8. 退出路径

取消关闭当前浮层并回到原对象；处理中锁定重复提交。跨页回程按所属领域要求清理，失败保留可重试出口。

## 9. 边界规则

Agent 删除按实际注入绑定销毁任务，准备中任务在注入前重新核对；同方式重新登录迁移绑定、不销毁任务。Git 凭证仅平台克隆/拉取使用，不注入 Agent；无真实目标仓库时不发送 secret。

验收逐条使用 CRD、AUTH 的 AC，不继续使用旧页自编编号；代码、实跑记录与视觉证据分别登记。

## 10. Git 凭证分区

Token 来源推导白名单；SSH 本地预检公钥和加密私钥；两种 secret 保存与提交立即清空。测试连接只使用白名单匹配的真实项目仓库；无目标明确说明，不用 host 根目录替代。首次成功 SSH 克隆记录真实已信任主机指纹，metadata 可核对但绝不回显密文。更换表单为空，删除确认列出相关项目，既有任务不受影响。
