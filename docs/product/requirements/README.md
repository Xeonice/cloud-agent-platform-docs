## 使用规则

需求描述做什么及其后果，AC 的「层级」是最低验证层。组件、API、SQLite、协议、Storybook 与跨仓浏览器分别证明实际执行的边界；规格条数不表示测试通过数量。执行入口见 [共享测试策略](../../shared/29-测试策略与测试Agent.md)。

[产品裁决](./decisions.md) 定义互斥分支与当前延后范围；同域正文应与裁决一起阅读。运行证据放在对应验收报告和 Jenkins 构建产物中，不在需求中保存阶段性实现百分比。参数标识符与 REQ/AC 编号的变更必须同步契约和验收映射。
