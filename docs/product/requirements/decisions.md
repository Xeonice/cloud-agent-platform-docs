# 当前产品裁决

本页记录仍有效的产品约定。Q 编号用于稳定引用，不保存迁移阶段的执行计划、稿件任务或实现进度。具体 Given/When/Then 见各域需求；下列适用性裁决优先于保留的互斥 AC。

## 1. 适用范围与互斥分支

| 条目 | 当前适用性 | 当前规则 |
| --- | --- | --- |

| AC-PRJ-053.3 | superseded | 同一成果弹层切换到删除确认，请求中冻结确认；与「其它行仍可用」的旧分支互斥，采用 PRJ-053.1 的同弹层确认。 |

## 2. 领域约定

### Q-PRJ-01 · 满 50 个项目时，新建项目的入口要不要置灰 {#Q-PRJ-01}

项目名额以服务端为准；新建入口保持可用，提交达到上限时就地说明并保留输入。

### Q-PRJ-02 · 改为空项目之后能不能再改回 Git 项目 {#Q-PRJ-02}

改为空项目不承诺以后能改回 Git 项目，也不显示未经确认的不可逆提示。

### Q-PRJ-03 · 树组头上，克隆中的项目写不写进度 {#Q-PRJ-03}

项目组头的计数表示任务数；克隆进度只在主区与新建项目进度视图展示。

### Q-PRJ-04 · 删项目时「还有活跃任务」的 409 用什么码 {#Q-PRJ-04}

活跃任务阻止删项目使用 PROJECT_HAS_ACTIVE_TASKS，和仍有成果的拒绝原因分开。

### Q-PRJ-05 · 删除被拦时 [去停止或销毁] 把人带到哪 {#Q-PRJ-05}

删除被活跃任务拦下后，关闭确认、筛选回全部、展开对应项目并滚入视野。

### Q-PRJ-06 · 「保留下来的成果」每一行写来源任务名还是 8 位短号 {#Q-PRJ-06}

成果登记时快照来源任务名，列表与删除确认使用该名字；拿不到时才用短号。

### Q-PRJ-07 · 从删除项目点 [去清理] 清完之后，要不要自动回到删除确认 {#Q-PRJ-07}

去清理成果后不自动返回删除项目确认，弹层不叠加；清理后从项目菜单重新删除。

### Q-PRJ-08 · 项目信息浮层关着时拉取失败，怎么让人看到 {#Q-PRJ-08}

拉取失败时自动打开项目信息浮层、保留焦点，并用 role="alert" 播报失败；成功只播报。

### Q-PRJ-09 · 顶栏项目 chip 的新文字 {#Q-PRJ-09}

空项目 chip 写「空项目」，未指定分支的 Git 项目写「远端默认分支」。

### Q-LCH-01 · 任务指令的长度按什么计数 {#Q-LCH-01}

任务指令按提交内容的 Unicode 码点计数，前端、契约和数据库口径一致。

### Q-LCH-02 · 启动进度的四格会「先打勾再回退」 {#Q-LCH-02}

启动四格的展示序、完成判定和重新启动行为采用 REQ-LCH-012 与 REQ-SBX-013；进度必须来自真实阶段。

### Q-LCH-03 · 新建任务里要不要能选镜像 {#Q-LCH-03}

新建任务有可选镜像字段，默认平台预制镜像；已启用、验证通过或有警告且适合当前 Provider 的可选。禁用 / 无效镜像保留在匹配列表中并说明原因，不可选；Provider 不兼容的不列。未预装所选 Agent 的 CLI 仅警告、不拦选择（REQ-LCH-004）。

### Q-LCH-04 · 「需要你处理」里三类怎么排 {#Q-LCH-04}

「需要你处理」按异常、可能卡住、等待输入排序；导航任务徽标只数等待输入。

### Q-LCH-05 · 「项目」下拉的默认项与顺序 {#Q-LCH-05}

没有当前项目时选树中第一个就绪项目；未搜索时列表顺序与树一致，当前项目置顶。改项目保留 Agent、镜像和指令，分支回默认并清空分支搜索词。

### Q-LCH-06 · 卡在其余三格时说什么 {#Q-LCH-06}

暂不能确认具体卡住阶段时用通用提示，不编造原因或进度。

### Q-LCH-07 · 项目、分支与镜像能否输入搜索 {#Q-LCH-07}

三个字段统一为 shadcn 可搜索单选 Combobox，只选已有对象。项目按 name、分支按完整 name、镜像按别名 / imageName / ref / tag 在已加载列表中做 trim 后、大小写不敏感的子串过滤；搜索词不提交、不持久化，也不改变已选值。分支默认入口与预制镜像默认入口始终可见，空项目没有分支字段。关闭浮层清空该字段搜索词；项目变更只额外重置分支及分支搜索词，保留 Agent / 镜像 / 指令。键盘、中文输入法与嵌套 Esc 采用 REQ-LCH-018；创建中锁定。

### Q-SBX-01 · 超时卡上写不写秒数 {#Q-SBX-01}

超时卡拿不到时长就不写秒数。

### Q-SBX-02 · 异常任务、重新启动中被取消的任务，销毁时给不给「留下来作为成果」 {#Q-SBX-02}

首次启动失败没有可保留成果；其它异常与从停止状态重新启动时取消的任务可选择保留代码副本，默认保留。

### Q-SBX-03 · 「代码副本」与「工作目录」两个词 {#Q-SBX-03}

上屏的任务工作区统一叫「代码副本」。镜像 WorkingDir 的「工作目录」含义独立，接口标识符不改名。

### Q-SBX-04 · 无头结果区 [发起全新任务] 的名字 {#Q-SBX-04}

无头结果区保留「发起全新任务」名称；与创建运行环境的入口区别由 REQ-SBX-035 定义。

### Q-SBX-05 · 无头产物的时间写法 {#Q-SBX-05}

无头产物时间按 REQ-SBX-034 展示后端 ISO 时间。

### Q-SBX-06 · 自动化发起的任务，要不要标「自动」并能回到来源规则 {#Q-SBX-06}

自动化任务通过持久化来源规则 ID 与名称快照标识来源，并能定位来源规则；无头模式本身不等同于自动化来源。

### Q-SBX-07 · 自动化发起的任务叫什么名字 {#Q-SBX-07}

自动化任务名称为「<规则名> #<运行序号>」，由后端产生。

### Q-AUTH-01 · 设备码页网络异常时的 [重试]：再查一次，还是换一串码 {#Q-AUTH-01}

设备码页网络异常的重试重新查询同一授权会话，不换码、不重置倒计时。

### Q-AUTH-02 · Claude Code 授权码被拒一次后，能不能直接再粘一次 {#Q-AUTH-02}

Claude Code 授权码被拒后可以直接重新取码并提交；底层会话失效时平台重新准备登录链接。

### Q-AUTH-03 · 关掉新建任务弹层再打开，登录面板保持展开还是收起 {#Q-AUTH-03}

收起、切走或关闭登录宿主取消授权；再次打开回到收起的空闲态，必须显式开始登录。

### Q-CRD-01 · 「配好即生效」的范围要不要扩大 {#Q-CRD-01}

生效凭证已删除或过期时，新配置的有效凭证自动生效；不能销毁仍在运行的任务来替换凭证。

### Q-CRD-02 · 两处删除的轻提示用词 {#Q-CRD-02}

删除成功提示明确指出删除的是 Agent 登录凭证还是 Git 访问凭证，符合对应领域的提示文案。

### Q-CRD-03 · 卡片上的 [测试连接] 测什么 {#Q-CRD-03}

Git 测试连接说明本次实际探测的目标；有回程仓库时测试该仓库，不把 SaaS 根地址的 not-found 误判为令牌无效。

### Q-ACC-01 · 口令会话要不要顺延；换口令要不要让已解锁的浏览器失效 {#Q-ACC-01}

口令会话不滑动续期。换口令时可选同时使已解锁浏览器失效，默认不选；固定会话签名环境变量时按 REQ-ACC-007 拒绝接口轮换。

### Q-ACC-02 · 锁定到期后，失败计数要不要清零 {#Q-ACC-02}

连续错误口令计数到成功解锁时才清零，锁定到期不自动清零。

### Q-IMG-01 · 镜像要求第②条「要有 WorkingDir」与平台不符 {#Q-IMG-01}

镜像要求与校验结论采用 REQ-IMG-003、REQ-IMG-007；具体不合格原因来自服务端，界面不另造要求。

### Q-IMG-02 · 注册弹层开着时，键盘到不了侧弹层的 [关闭] {#Q-IMG-02}

注册弹层打开时焦点只在最上层弹层循环；先用 Esc 关闭它，再关闭镜像要求侧弹层。

### Q-IMG-11 · 运行参数摘要条目很多时截不截 {#Q-IMG-11}

运行参数摘要全部列出并整段折行，不以省略前三条隐藏配置。

### Q-IMG-51 · 「一张镜像都没有」时的说法与主动作 {#Q-IMG-51}

镜像列表空态引导注册镜像；注册后在当前列表和新建任务的镜像字段可选。

### Q-IMG-03 · 运行参数跟着版本走，还是属于整张镜像 {#Q-IMG-03}

运行参数属于镜像版本；新版本继承旧版本配置，由服务端复制 Secret 密文，按下方适用性表采用继承分支。

### Q-IMG-04 · 禁用预置镜像要不要先确认 {#Q-IMG-04}

禁用预制镜像先给非破坏性确认，取消获得焦点；说明新任务默认受影响、已有任务不受影响，以及重新启用或改选镜像的出口。

### Q-IMG-05 · 预置镜像下载的按钮叫什么 {#Q-IMG-05}

下载入口按钮叫「准备镜像」，块标题叫「下载到本机」；诊断下一步使用相同动作名称。

### Q-IMG-06 · 「预置」与「预制」 {#Q-IMG-06}

正文和徽标统一使用「预制镜像」；isBuiltin、preset 等接口标识符不变。

### Q-IMG-07 · [定位到该镜像] 的高亮保留多久 {#Q-IMG-07}

定位镜像时先清过滤、滚到可见并把焦点放在卡片；高亮保持到下一次定位或离开页面。

### Q-IMG-08 · 镜像别名属于谁、怎样编辑与检索 {#Q-IMG-08}

别名属于整张 Image，预制 / 自定义均可编辑、所有版本共享，允许重名。注册新镜像可填；已有镜像通过卡头独立编辑、不重验，注册已有镜像不能隐式覆盖别名。原输入先拒绝 Unicode Cc 控制字符与 U+2028 / U+2029，再 trim，最多 64 Unicode 码点；null / trim 后空白清除，省略保持。别名优先、真实坐标辅助；镜像页与任务选择器都匹配别名 / imageName / ref / tag。改名不改变坐标、digest、启用状态、运行参数、版本操作或任务绑定；失败留草稿、取消恢复、成功同步已加载视图（REQ-IMG-060、061）。

### Q-SYS-16 · 系统状态「出网代理」保存后到底管哪些出网 {#Q-SYS-16}

保存的出网代理用于联网检查，不承诺镜像下载或沙箱内 Agent 使用它；检查能连通不等于下载带宽充足。

### Q-SYS-17 · 资源卡口径句里「本机最多 M 个」从哪来 {#Q-SYS-17}

remainingTasks、registeredTasks、maxTasks 与 basis 来自默认资源准入的同源契约；缺数据时不自行推算。

### Q-SYS-18 · 严重档「现在建不了新任务」只在主数字为 0 时说 {#Q-SYS-18}

只有 remainingTasks 为 0 时才说现在建不了新任务；严重水位仍须展示实际准入结论。

### Q-SYS-19 · 几个维度同时越线时怎么给下一步 {#Q-SYS-19}

多个资源维度越线时分别给下一步，严重项在前。

### Q-SYS-20 · 代理地址没写协议（`host:port`）怎么办 {#Q-SYS-20}

代理 URI 必须以 http:// 或 https:// 开头；拒绝无协议和不支持的协议，空字符串可清空配置。

### Q-SYS-21 · 连接卡上两处写「正常」 {#Q-SYS-21}

连接卡区分真实正常、未测量与未知；不把未测量结果标成正常。

### Q-SYS-22 · 沙箱环境「故障 / 失败率偏高」时给什么下一步 {#Q-SYS-22}

Provider 故障或失败率偏高时，日志与诊断出口按 REQ-SYS-030、031 展示实际可用能力。

### Q-SYS-23 · 「保留卷」与「保留下来的成果」同物两名 {#Q-SYS-23}

统一叫「保留下来的成果」，资源卡写「成果占用」、动作写「清理成果」；retainedVolumes 等契约名称不变。

### Q-AUD-03 · 点「查看该任务完整时间线」时，其余筛选要不要清回默认 {#Q-AUD-03}

查看任务完整时间线时，类别、仅告警、起止时间回到默认，添加可移除的任务筛选。

### Q-AUD-04 · 「保留工作区卷」那一行要不要给 [查看该任务完整时间线] {#Q-AUD-04}

保留代码副本事件可以按来源任务 ID 查看任务时间线。

### Q-WB-01 · 「自动化需关注」横幅要不要按全部项目判定 {#Q-WB-01}

自动化需关注横幅按全部项目判定，点名项目与规则，入口定位到被点名规则的项目；概览读取失败时不出横幅。

### Q-WB-02 · 「未命名项目 N」会不会复用已删除项目的号 {#Q-WB-02}

未命名项目 N 按现有名称最大号加一，删除后允许复用编号。

### Q-WB-03 · 治理横幅的数据多久刷一次 {#Q-WB-03}

全局治理数据在页面进入与窗口回到前台时读取，系统状态页另按其轮询周期更新。

### Q-WB-04 · 设置区里按 Esc：弹层或表单开着时怎么办 {#Q-WB-04}

Esc 优先关闭最上层可取消浮层，忙时冻结的确认不关闭；没有浮层时才按页面的返回规则处理。

### Q-WB-05 · 终端里没有可复制的内容时，提示用失败样式还是中性 {#Q-WB-05}

终端没有可复制内容时按 REQ-WB-063 使用失败提示。

### Q-AUT-01 · 超时在运行历史里怎么画 {#Q-AUT-01}

运行超时归失败类，在运行历史显示失败图标和真实原因。

### Q-AUT-02 · 跑完收尾之后，已结束的运行上 [打开任务] 去哪 {#Q-AUT-02}

运行中提供「打开任务」；已收尾运行提供「查看成果」，打开项目成果列表并定位来源任务。

### Q-AUT-03 · 删除规则的确认里，数量从哪来 {#Q-AUT-03}

删除规则预检返回真实历史数、保留成果与进行中运行；读取失败不显示假数字。

### Q-AUT-04 · 从 [查看原因] 进来，要不要把那条滚进视野并移焦 {#Q-AUT-04}

查看失败原因自动展开对应运行，滚到正文顶部并把焦点放在其收起按钮；用户选过另一行后不再抢回。

### Q-AUT-05 · 因凭证跳过的运行，要不要单独出横幅 {#Q-AUT-05}

因凭证跳过由 Agent 凭证治理横幅提示；运行历史和 Webhook 保留实际跳过结果，不另说规则已暂停。

### Q-AUT-06 · 新建表单什么时候亮出字段错误 {#Q-AUT-06}

字段修改或失焦后才显示错误；初次打开不播报未填写。存在错误时保存不可用。

### Q-DEP-01 · 写入时才发现离线，怎么接 {#Q-DEP-01}

写入时发现离线，给「回到联网检查」并自动重跑，用户明确确认离线后才能完成。

### Q-DEP-02 · 准备镜像要不要能取消 {#Q-DEP-02}

准备镜像不提供取消；下载不阻塞初始化继续，失败可重试，避免留下半注册版本。

### Q-SYS-01 · 入口范围：① ⌘K ② 环境类错误上的 [诊断] ③「无法确认平台状态」横幅是否自动诊断 {#Q-SYS-01}

命令面板与系统页可运行诊断；环境类错误卡提供运行诊断；未知状态横幅不会自动启动诊断。

### Q-SYS-02 · 资源水位回答「实时占用」还是「还能再发几个」 {#Q-SYS-02}

资源主数字回答还能再发几个任务，依据后端 remainingTasks，不用实时占用率自行推算名额。

### Q-SYS-03 · 文案以哪份为准 {#Q-SYS-03}

逐字文案以当前代码文案表为准，规格定义必须表达的信息与后果。

### Q-SYS-04 · 沙箱环境健康口径 {#Q-SYS-04}

沙箱环境健康采用最近一小时失败率，并明确无样本状态。

### Q-SYS-05 · [查看日志] {#Q-SYS-05}

查看日志采用 REQ-SYS-031 的 Provider 日志接口，读取不到明确说明原因。

### Q-SYS-06 · 连接卡测不到的项 {#Q-SYS-06}

本页未测量的连接项写明原因，不伪装成正常。

### Q-SYS-07 · 访问保护区块 {#Q-SYS-07}

系统页访问保护设置区块延后；访问口令行为由 ACC 域、接口参数、横幅与部署说明定义。

### Q-SYS-08 · 出网代理卡纳入规格 {#Q-SYS-08}

系统页包含出网代理卡，保存与错误处理采用 REQ-SYS-060。

### Q-SYS-09 · 布局以哪份为准 {#Q-SYS-09}

系统页采用共享 AppFrame 与当前页面组件布局；加载骨架应与实际卡片位置和高度匹配。

### Q-SYS-10 · 保留卷超量的全局横幅 {#Q-SYS-10}

成果占用、磁盘和 Agent 凭证到期纳入全局治理横幅，展示与关闭策略归 WB 域。

### Q-SYS-11 · 保留卷倒计时口径 {#Q-SYS-11}

成果按各自登记时间与保留期得出到期时间，停止任务不开始成果倒计时。

### Q-SYS-12 · 「活跃任务数」含不含排队与残留 {#Q-SYS-12}

已登记任务数包括停止任务；任务名额的准入与当前瞬时 CPU 占用是不同口径。

### Q-SYS-13 · CPU 口径 {#Q-SYS-13}

CPU 指标使用当前运行环境的真实可用资源并说明口径，不复用其它宿主的固定容量。

### Q-SYS-14 · 升级与备份占位 {#Q-SYS-14}

系统页面不提供升级与备份操作；实际部署维护与回退采用部署说明。

### Q-SYS-15 · 磁盘阈值独立于 CPU / 内存 {#Q-SYS-15}

磁盘阈值独立于 CPU/内存阈值，使用 REQ-SYS-011、012 的参数。

### Q-DIA-01 · 第 ⑨ 项纳入、「固定八项」怎么改 {#Q-DIA-01}

诊断项目清单以服务端首帧为准，包含鉴权运行环境项，不硬编码固定八项。

### Q-DIA-02 · 诊断用词以谁为准 {#Q-DIA-02}

诊断进度用「第 N 项」与「超时未响应」，具体项标题与服务端清单一致。

### Q-DIA-03 · 后端起不来时的兜底脚本 {#Q-DIA-03}

后端不可用时使用 REQ-DIA-030 的只读诊断脚本，结果不能自动修改配置。

### Q-DIA-04 · 「可用空间低于 20 GB 也告警」纳入 {#Q-DIA-04}

可用磁盘告警采用 REQ-DIA-012 的实际阈值；界面不额外创造另一套准入阈值。

### Q-AUD-01 · [查看该任务完整时间线] 去哪 {#Q-AUD-01}

任务完整时间线在审计页就地过滤，显示可移除的任务条件。

### Q-AUD-02 · 导出包四件 {#Q-AUD-02}

日志导出包含 REQ-AUD-006 定义的四件内容，并执行脱敏与截断规则。

### Q-DS-17 · DS约定 {#Q-DS-17}

破坏性删除使用同一弹层内的确认阶段；请求中冻结确认与关闭，失败保留对象并允许重试。

### Q-DS-21 · DS约定 {#Q-DS-21}

面向用户使用任务、代码副本、镜像下载源等领域词，错误码放在诊断细节，标题先说明现象。

### Q-DS-27 · DS约定 {#Q-DS-27}

查找使用统一命令面板，快捷键和搜索排序采用 WB 域；自动化入口按下方具体领域裁决。

### Q-DS-28 · DS约定 {#Q-DS-28}

项目总览是工作台回落页；当前任务删除或对象不存在时回到总览并说明原因。

### Q-DS-29 · 新建任务弹层要不要「项目」下拉 {#Q-DS-29}

新建任务保留项目可搜索单选，列出全部匹配项目；只有就绪项目可选，未就绪项目显示原因并不可选，不在任务弹层内嵌套新建项目（REQ-LCH-001、018）。

### Q-DS-30 · 总览工具条 {#Q-DS-30}

总览工具条与树共用筛选，不提供卡片/列表切换。

### Q-DS-31 · 首次进入的建项目引导 {#Q-DS-31}

首次进入以两张卡引导 Git 项目与空项目，均打开同一个新建项目弹层。

### Q-DS-32 · 三种治理横幅（含 Q-SYS-10） {#Q-DS-32}

治理横幅包含磁盘、成果占用与 Agent 登录到期，按 WB 优先级与抑制规则展示。

### Q-DS-33 · [清理保留卷] 去哪 {#Q-DS-33}

清理成果打开跨项目成果视图，按项目分组。

### Q-DS-34 · 实例菜单「文档」 {#Q-DS-34}

实例菜单不提供虚构的文档入口；操作只连接当前真实页面与能力。

### Q-DS-35 · 三个小口径 {#Q-DS-35}

删除对象回落总览，拉取结果原位播报，代理保存只承诺实际作用范围。
