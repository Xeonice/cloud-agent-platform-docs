# P22 - 异常与恢复（2026-10）

## 1. 错误语义

wire码与retryable来自 [接口契约](../shared/10-接口契约与类型共享.md)。产品页面按领域要求映射固定人话，不原样显示厂商英文/内部错误码/secret。未知错误给可执行的重试或诊断出口。

### 1.1 门口拒绝

参数、容量、权限与引用校验在资源创建前拒绝；零副作用需真实数据库/Provider调用验收。409竞争保持旧对象不变，刷新预览后再由用户决定。

## 2. 链路异常

项目克隆排队/取消/中断/权限/网络分别恢复；登录会话取消/到期/网络/厂商拒绝分别说明；任务创建失败保留最后阶段；终端断线不丢最后输出；自动化最终状态与通知失败分开；镜像引用与下载失败真实展示。

## 3. 诊断

界面诊断通过真实SSE逐项显示结果；独立diagnose.sh用于服务不可达环境，读取真实DATA_ROOT、端口和运行条件。未测完/不可读必须明确说明，复制与导出脱敏。

## 4. 验收原则

验证失败发生前已到达目标阶段，再验证取消与失败的无副作用。文案、焦点与布局由实际浏览器补查；存储、并发和回收由真实服务/SQLite/协议验收。全部具体标准使用领域AC，不再维护旧18项缺口清单。
