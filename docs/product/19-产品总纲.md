# P19 - 产品总纲（2026-10）

## 1. 定位

私有化部署的云 Agent 工作平台。项目组织代码与任务，任务是实际运行单元；交互式终端、无头自动化、凭证与镜像管理围绕同一个工作区展开。

## 2. 使用者

需要在自己的服务和数据目录运行 Codex/Claude Code 的开发者或团队；无多用户帐号体系。部署访问口令与厂商Agent凭证是不同的保护面。

## 3. 当前产品范围

按 [完整领域规格](./requirements/README.md) 的247 REQ/1016 AC实现：项目/工作台、发起与生命周期、Agent/Git凭证、默认口令、镜像、系统诊断/审计、自动化、初始化。明确deferred/superseded项按已选裁决处理，适用性见当前产品裁决。

## 4. 质量要求

状态、数量和后果来自真实服务结果；读取失败与空集合分开；取消与销毁可验证；敏感值不回显；后台进程和临时资源有可回收生命周期；主题、窄屏、焦点和固定操作出口可用。

## 5. 完成度

以当前领域 AC 与实际验收结果判断。功能实现、代码审查、测试执行与真实外部部署验证分开记录；规格条数和截图数量不能替代产品完成度。

## 6. 演进

后续需求以当前规格为基础单独裁决，并同步实现、契约和验收映射。多帐号、多节点与外部部署条件需要明确产品范围。
