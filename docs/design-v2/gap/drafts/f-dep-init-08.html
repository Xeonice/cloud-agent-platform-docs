沙箱镜像

平台自己的沙箱镜像备齐了没有。这一步排在本机资源之前是刻意的：它要先能联网/走代理，而镜像体积又是下一步磁盘评估里最大的一块。

镜像检查共 5 项，任一项未通过即止 —— 每一项的修复动作都不一样。

  1. 第 1 项（共 5 项） · 该用哪张镜像（没指定 = 平台按你的机器自动选）通过
  2. 第 2 项（共 5 项） · 镜像下载源里有没有这张镜像未通过

    镜像下载源里找不到这张镜像

    'localhost:5001/platform/sandbox:v2' 解析不到：manifest unknown。'localhost:5001/platform/sandbox:v2' 的字节在这台机器上够不着：本机 docker 镜像库里没有、发布包里没有匹配这台机器的那一份、也没有配上游坐标（SANDBOX_PRESET_IMAGE_SOURCE）。这一格确实只能自己构建，平台代劳不了。 把镜像推上去，或把地址改成推过的那个：镜像下载源里找不到这张镜像，平台既检查不了它也拉不下来。 docker build -t localhost:5001/platform/sandbox:v2 api/images/platform-sandbox && docker push localhost:5001/platform/sandbox:v2 错误码 PRESET_IMAGE_NOT_IN_REGISTRY
  3. 第 3 项（共 5 项） · 来源对不对：是不是平台自己构建的那一张未检查
  4. 第 4 项（共 5 项） · 平台检查过没有、能不能选用未检查
  5. 第 5 项（共 5 项） · 有没有下载到本机（只影响首个任务的耗时）未检查
