# 镜像 CLI 版本元数据 · 后端变更

对应 [PRD](../../product/changes/2026-10-17-镜像CLI版本信息.md)、REQ-IMG-062/063；联合验收见[独立测试计划](../../testing/changes/2026-10-17-镜像CLI版本信息测试计划.md)。

## 1. 来源、解析和边界

OCI config 的 `platform.runtimeVersions` 为 JSON 字符串，解析为只含 `codex` / `claude-code` 的 `Record<string, string>`。接受不带 `v` 的精确 SemVer，允许合法 prerelease/build、单项最多 128 字符；过滤其他键和非法单项。缺标签、坏 JSON、数组/null 等非对象得到 `{}`，一项无效不丢另一有效项。不信任任意标签文本，不原样回显 HTML，也不将不可信元数据送进 shell。

与已有 manifest/config 元数据解析共用 registry 认证、超时和 digest 校验；解析层无需 pull 镜像层、Guest、Docker exec 或模型凭证。缺/坏版本 label 不添加镜像不可用错误，也不等价于未预装；预装警告继续由 `platform.supportedRuntimes` 判定。

## 2. 领域与存储

`ImageManifest` 增加 `runtimeVersions`，与该行 digest 绑定；不放共享 Image、环境变量或平台版本。迁移 29 为 `image_manifests` 增加兼容 JSON 列，旧行按 `{}` 读取；同步实际 SQLite schema、repository、mapper、snapshot/journal，解析旧 nullable 值不报错。

首次注册和新 digest 插入保存本次解析值。同 digest 幂等注册与重新验证只补旧行缺失的 runtime 键，不覆盖已有有效声明；重新验证发现 tag 指向不同 digest 时只报告上游声明，不改旧行版本、状态或声明。检查更新不落库，current 只返回 digest/resolvedAt，前端按 digest 从已有列表匹配其声明；upstream.validation 返回本次验证值；激活/回滚返回所选 digest 自己的声明。配置继承只复制既有 imageConfig，不复制另一 digest 的 CLI 声明。

GET 列表只读数据库，不联机解析、不执行 CLI；普通别名、环境变量或启停 PATCH 不修改版本声明。正式服务 API 对未知值返回 `{}`，传输字段保留 optional 以兼容老服务。

## 3. 响应契约

既有 `ImageManifestResponseDto` 与 `ValidationOutcomeResponseDto` 增加 `runtimeVersions?: Record<string, string>`，只读。注册的 manifest 和 validation、预检、重新验证、更新对比通过既有嵌套 DTO 传递；不向 POST/PATCH 请求增加可写字段。重验上游漂移时 outcome 中的值属于 upstreamDigest，不能冒充 currentDigest。

权威接口见 [10](../../shared/10-接口契约与类型共享.md#64-image)、[27](../27-接口暴露设计（DDD到API与MCP）.md)。API 发射 OpenAPI 后同步 Web codegen；旧 API 不带该字段时前端展示未知，不以宿主工具或服务包版本补齐。

## 4. 官方构建与测试

官方 Dockerfile 真实执行并核对固定版本的 `codex --version` 与 `claude --version`，通过后新增唯一 JSON label。版本常量、构建参数、label 与发布身份中的声明保持一致；本轮不改固定 CLI 版本。

测试覆盖解析边界、真实 registry/config 解析、fresh SQLite 迁移与重启、同 digest 回填、tag 漂移零错写、HTTP/生成契约和列表零外部副作用。任务现有 runtime_installation 的实测仍归任务，不作为镜像声明来源；不新增周期 CLI 探针或模型连通测试。
