# 镜像 CLI 版本展示 · 前端变更

对应 [PRD](../../product/changes/2026-10-17-镜像CLI版本信息.md)、[原 v2 增量设计](../../design/image-cli-versions.html)与 REQ-IMG-062/063；测试独立维护在[联合计划](../../testing/changes/2026-10-17-镜像CLI版本信息测试计划.md)。

## 1. 数据接入

消费生成的 `runtimeVersions?: Record<string, string>`，经单一纯展示函数按 `codex`、`claude-code` 固定顺序转换；显示名为 Codex、Claude Code。字段省略、空 map、单项缺失或无效时该项显示「未报告」。有效值以普通文本渲染；不从 supportedRuntimes、镜像 tag、平台版本或浏览器/宿主 CLI 推断。

聚合镜像卡时保留每条 manifest 的 map，不能取第一行覆盖所有历史；check-update.current 仅 digest/resolvedAt，按 digest 匹配已加载列表的当前声明；upstream 使用 validation DTO 的声明。重新验证 digestChanged=true 时只更新上游提示，不将结果写入当前镜像卡。以 Query 的真实刷新结果同步管理页与任务选项，不自行执行 CLI。

## 2. 展示位置

| 位置 | 增量 |
| --- | --- |
| 当前镜像卡 | 原版本信息区增加「镜像声明」及两项值；保留 digest、验证结果与所有原操作 |
| 历史版本 | 每个 digest 行追加该版 Codex/Claude Code，窄屏换行 |
| 检查更新对比 | 当前/上游两列或两行各自显示两个版本；未知值不抹去 digest 对比 |
| 注册预检 | 如接口返回版本声明，在当前验证结果内展示；不改变 valid/warning/invalid 或保存条件 |
| 新建任务镜像选项 | 默认项、普通候选和已选项追加两项值，保留 ref；可选性、稳定 ID 与键盘行为不变；保留坐标/别名搜索并额外支持 CLI 版本搜索 |

标题或辅助说明标注「镜像声明」，可访问说明为「任务实际版本以任务环境为准」。自定义派生镜像可能继承标签，不写「实测」「已核验安装」或健康/在线标记。任务自己的已实测版本继续属于任务，不显示为镜像整体版本。

## 3. 实现与验证

保持 view/container 边界，wire 类型来自 OpenAPI；复用纯格式化函数，避免多处各写未知处理。版本文本采用已有字号/色彩 token，长合法版本和长 ref 可换行，暗亮主题、390px 窄屏不横向溢出。新增信息不抢焦点、不占按钮、不改变复制 digest/ref 行为。

组件验收覆盖已知/部分未知/全部未知/旧 API、历史切换、对比隔离与选择器身份；真实协议联调证明保存、重载和默认项来自服务端元数据；浏览器验证布局、主题、键盘与无运行错误。原型是展示证据，不能替代持久化或真实构建门禁。
