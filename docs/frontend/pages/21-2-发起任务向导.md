# F21-2 · 发起任务向导前端实现

本页对应 [产品说明](../../product/pages/21-2-发起任务向导.md)；[LCH 需求](../../product/requirements/LCH.md) · [AUTH 需求](../../product/requirements/AUTH.md) · [SBX 需求](../../product/requirements/SBX.md) 定义全部 AC。组件清单取当前 workspace，验收结果以运行产物为准。

2026-10-09 变更：项目、分支、镜像改为可输入搜索的单选控件。第 10–13 节与[交互设计预览](../../design/task-search-image-alias.html)记录当前设计；业务视图已接入统一 `SearchSelect`，执行证据见[变更与验收记录](../../product/changes/2026-10-09-任务选择与镜像别名.md#8-本轮交付检查)。

本轮设计增量接续原有 v2 全流程设计稿，来源、复制处理与文件校验值见 [BASELINE.json](../../design/v2-base/BASELINE.json)。保留原页面外壳、侧栏与导航；任务弹层保持 512px 宽度和原字段栈、纵向 Agent 列表、任务指令计数、凭证区域及「发起任务并打开终端」主按钮文案。本页增量仅为项目、分支、镜像三个选择器的输入搜索；镜像注册别名和卡头独立行内编辑按镜像管理页处理。

## 1. 页面职责

在同一个表单选择项目、Agent、任务指令与镜像；凭证不足时原位配置，成功后继续原表单。

## 2. 路由与骨架落点

新建任务弹层；`/?new=1&project=<id>` 查询参数深链入口。使用 AppFrame/SettingsLayout 与 AppDialog；DialogSections 固定头尾，正文独立滚动。

## 3. 组件树

SandboxTerminalContainer、NewSandboxPanelView、SandboxLifecycleContainer、AuthGateContainer、SandboxStartupProgressView、EnvVarEditorView。Container 编排查询与命令，view 只接 props；wire 使用生成 DTO。

当前 `NewSandboxPanelView` 的三个字段共用 `components/ui/search-select.tsx` 的 `SearchSelect`。组件采用 shadcn 的 Radix Popover + cmdk Command 组合，Popover 固定为与现有 Dialog 兼容的 1.1.23，共享焦点与 dismiss 层依赖。搜索采用显式本地子串匹配，不使用 cmdk 的默认模糊重排。

生产组件实施沿现有视图作受控替换，复用既有布局、尺寸、文案、token 和数据编排。现 Web 与 v2 原稿的个别视觉偏差单独记录，不能据此扩大为本轮页面重绘；设计增量验收需与上述原稿逐项对照，保留未涉及的字段、鉴权、计数和动作。

## 4. 状态与数据接入

GET projects/runtimes/images；POST sandboxes；runtime auth begin/status/complete/cancel 与 secret；创建阶段事件。

后端结果由 Query 持有，选择与临时编辑由 Zustand/组件持有；事件失效相关 query，不使用事件名称本身冒充业务状态。

## 5. 交互实现要点

选择可用项目与镜像；缺凭证只展示折叠闸门，点配置才展开，点开始登录才启动后端会话。发起后显示阶段进度，失败保留最后阶段并提供有意义的出口。

新建项目入口位于工作台或项目总览，不嵌套进新任务弹层；任务指令在原位登录期间保留；服务端最终决定容量与资源是否可用。

## 6. 状态矩阵落地

项目/Agent/镜像各自加载、失败、无可用项；未配置/已过期凭证阻止发起；即将过期给建议；创建中的进度不得伪造百分比；取消、超时和失败分别处理。

未知数据不可转换为零、成功或空集合。颜色取 v2 语义 token，图标为 SVG；控件保持可访问名称和焦点。

## 7. 本页测试设计

组件验收位于 `web/src/acceptance/`，本域场景：launch / credential-access / sandbox-lifecycle。真实 container + HTTP 边界验证交互与副作用。Storybook 验证 view 变体；生产构建浏览器验收验证实际页面与布局。

## 8. 依赖与契约

OpenAPI 生成类型与 shared schema 是传输形状依据。新预览接口的真实性由后端 SQLite/协议验收验证；浏览器固定数据只用于可重现视觉，不能证明真实外部基础设施健康。

## 9. 验证计划

本页按对应领域的 Given/When/Then 维护验收映射。计划、代码审查、测试执行与视觉审查分别记录；测试名称或截图存在不能证明全部 AC 实跑。

## 9.2 关键链路

Storybook 核对当前视图状态，生产构建与跨仓浏览器验证真实路由和页面装配；暗/亮主题、桌面与窄屏记录错误、溢出、焦点与截图。

## 9.3 证据与缺口

## 10. 搜索单选设计（已实现）

对应 REQ-LCH-018，保留 REQ-LCH-001、004 的项目预选、可选分支与默认镜像语义。三个控件的视觉与交互一致：触发器显示当前选择和展开图标，展开后顶部为搜索框，下方为可滚动的结果列表；已选项有勾选标记，禁用项保留原因，底部可显示结果数量。输入只用于筛选，必须点选或用键盘确认列表项才改变字段值。

| 字段 | 搜索范围与展示                                                                                                               | 值与默认项                                                            | 保留约束                                                                                                                  |
| ---- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 项目 | 按项目名称筛选；名称后保留「克隆中」「克隆失败」原因                                                                         | 选中值为 `projectId`；沿用当前入口的预选规则                          | 全部项目可见，只有 `cloneStatus=ready` 可选；当前项目置顶，其余保持原列表顺序；无匹配不自动选其他项目                     |
| 分支 | 按完整分支名筛选；长名称截断时仍可获取完整名称                                                                               | 选中值为分支名；独立保留「跟随项目当前的分支（默认）」入口，值为 `''` | 分支来自所选项目的本地引用；空项目不显示、不请求；不自动选 `main`，不接受输入创建新分支                                   |
| 镜像 | 按 `imageAlias`、原始镜像名 `imageName`、完整 ref、tag 筛选；有别名时主行显示别名、次行显示 ref，无别名时以真实 ref 为主标题 | 自定义镜像值仍为 `imageId`；独立保留平台预制镜像默认入口，值为 `''`   | 别名重复时用 ref 消歧；隐藏 provider 不兼容项；禁用/invalid/pending 项显示原因且不可选；未预装当前 Agent 仅给警告，仍可选 |

采用去首尾空白、不区分大小写的包含匹配，保留原排序。默认分支和默认镜像入口不被搜索词过滤；它们不是搜索自动改选的结果。清空关键词恢复全部候选项；清空关键词、关闭下拉、无匹配或重新打开均不改变已选值。项目保留 REQ-LCH-001 的预选：项目上下文入口预选当前项目，没有当前项目时预选树中首个就绪项目；搜索不能自动改选。没有就绪项目时入口不打开任务弹层，按原规则说明原因。

镜像别名显示读取服务端 `imageAlias`，设置入口位于镜像管理页。别名校验统一为：先拒绝原始输入中的 Unicode `Cc` 控制字符及 `U+2028`/`U+2029`，再 trim、按最多 64 个 Unicode 码点计数。注册表单未填写或 trim 后为空时省略 alias，保持既有注册幂等行为；已有 Image 的别名不能通过注册清除，应到卡头独立编辑，独立编辑清除才明确发送 `alias: null`。搜索控件不重新保存或修改别名。

三个字段搜索均在已加载的列表中完成，不新增每次键入的请求。关键词仅存在控件局部 UI 状态，不写 URL、Zustand 持久化或浏览器存储，也不传入 `POST /sandboxes`。创建请求沿用当前接口：项目提交 ID，分支缺省时省略 `branch`，默认镜像沿用现有缺省，别名与搜索词不参与镜像解析。

改选项目时清空分支选择与分支搜索词，保留 Agent、镜像和任务指令；分支查询继续以 `projectId` 为 query key 隔离。旧项目请求迟到不能覆盖当前项目列表，空项目不能触发 `/branches` 请求。修改镜像别名后刷新镜像 query，只更新显示与搜索，保持已选 ID；别名不能改变镜像的 provider、验证结论或启动版本。

## 11. 搜索控件状态矩阵（已实现）

| 状态           | 控件与提示                                                        | 发起行为                                                                                    |
| -------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| 初始/已选择    | 保留当前项目/树中首个就绪项目预选；展开后搜索框为空，已选项有标记 | 搜索不自动改选项目；Agent 仍必选不预选，分支仍跟随项目默认                                  |
| 加载中         | 用可访问的加载提示或骨架，不用空结果冒充加载                      | 项目未确认就绪时不能发起；分支加载不拦创建；镜像按现有默认/显式选择规则处理                 |
| 数据读取失败   | 显示字段的失败文案；失败与无匹配分开呈现                          | 分支降级为默认且不拦创建；镜像默认可按既有规则降级，显式/重新发起镜像未经确认时保留阻断原因 |
| 无数据         | 明确「没有可选项目/分支/镜像」，不编造候选项                      | 无就绪项目时入口不打开弹层；已打开弹层失去就绪项目时不能发起；分支与镜像仍保留默认入口      |
| 搜索无匹配     | 显示「没有找到匹配的…」及清空搜索入口；已有选择保持               | 不改选、不发起请求、不将关键词提交为字段值                                                  |
| 匹配到禁用项   | 名称与禁用原因可读，鼠标/Enter 均不能选中                         | 不绕过 ready、验证状态或启停约束                                                            |
| 当前镜像不可用 | 重新发起的旧镜像保留不可用占位及改选原因，搜索不掩盖字段外原因句  | 保留原阻断，不能因过滤隐藏旧选项而静默改成默认                                              |
| 创建中         | 三个触发器与搜索交互锁定，展开的列表收起，字段仍可读              | 保留现有防重复提交、关闭锁定及失败恢复行为                                                  |

## 12. 键盘、焦点与响应式（已实现）

触发器有可访问字段名、`aria-expanded` 和列表关联；搜索输入有独立名称（如「搜索项目」），列表项表达选中与禁用状态。提示通过字段描述关联，搜索无匹配使用 `role=status`，不能把正常筛选报成错误。

Tab 到触发器，Enter/Space 打开并将焦点移到搜索框；上下键移动候选项，Enter 确认可用项并收起，焦点返回原触发器。第一次 Esc 只关闭当前下拉，弹层保持打开；下拉关闭后再次 Esc 才遵循任务弹层的关闭规则。点击下拉内容不能被当作外层遮罩点击，点击外部关闭下拉也不能误触发发起。

中文输入法组合期间不把 Enter 当作选中或提交，不响应会打断组合的列表导航；组合结束后才按完成的文本筛选。Tab/Shift+Tab 维持任务弹层内的合理焦点顺序，不产生第二个不可退出的焦点陷阱；控件中的 Enter 不冒泡触发任务创建。

下拉与触发器同宽，并根据可视区域向上/向下展开；最大高度受可视区域限制，结果列表内部滚动，搜索框不随列表滚动。弹层正文滚动时正确定位下拉，Portal 层级高于弹层正文且在其交互范围内。桌面、窄屏和浏览器缩放下不超出视口，长项目名、分支名和镜像 ref 不撑宽弹层；任务页脚主按钮始终可见。暗/亮主题沿用 v2 语义 token。
