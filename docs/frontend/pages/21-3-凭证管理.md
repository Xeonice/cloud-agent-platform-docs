# F21-3 · 凭证管理前端实现

本页对应 [产品说明](../../product/pages/21-3-凭证管理.md)；[CRD 需求](../../design-v2/gap/product/CRD.md) · [AUTH 需求](../../design-v2/gap/product/AUTH.md) 定义全部 AC。组件清单取当前 workspace，验收结果以运行产物为准。

## 1. 页面职责

分别管理 Agent 的帐号登录/API Key 与平台 Git 凭证。显示打码标识、有效期、实际生效方式与删除后果。

## 2. 路由与骨架落点

`/settings/credentials`；Git 回程 `?section=git`。使用 AppFrame/SettingsLayout 与 AppDialog；DialogSections 固定头尾，正文独立滚动。

## 3. 组件树

CredentialsContainer、RuntimeCredentialsSection、RuntimeCredentialCard、AuthMethodRadioRow、AuthGateContainer、GitCredentialsSection、GitCredentialCard、RevokeConfirmDialog、DeleteGitCredentialConfirm。Container 编排查询与命令，view 只接 props；真实服务数据使用生成 DTO。

## 4. 状态与数据接入

runtimes、credentials、auth-mode；runtime credential deletion-preview/DELETE；Git 保存、测试、删除；项目仓库列表用于测试目标与相关项目展示。

后端结果由 Query 持有，选择与临时编辑由 Zustand/组件持有；事件失效相关 query，不使用事件名称本身冒充业务状态。

## 5. 交互实现要点

按 Agent 独立单选分组。切换已配置方式先确认，确认前徽标与单选不动；未配置方式原位补配。删除先读取真实凭证绑定，统一框按后果顺序展示，默认焦点取消。

Agent 删除按实际注入绑定销毁任务，准备中任务在注入前重新核对；同方式重新登录迁移绑定、不销毁任务。Git 凭证仅平台克隆/拉取使用，不注入 Agent；无真实目标仓库时不发送 secret。

## 6. 状态矩阵落地

两个分区独立骨架与错误重试；搜索只匹配名字和已显示的打码片段；读取失败不当作未配置。过期/即将过期显示下一步；未知删除清单明确可重试。

未知数据不可转换为零、成功或空集合。颜色取 v2 语义 token，图标为 SVG；控件保持可访问名称和焦点。

## 7. 本页测试设计

新版验收位于 `web/src/acceptance/`，本域场景：credential-access / git-credential-workflows。真实 container + HTTP 边界验证交互与副作用；旧单测已退休，不把旧覆盖率当验收。Storybook 验证 view 变体；设计 runner 验证实际页面状态与布局。

## 8. 依赖与契约

OpenAPI 生成类型与 shared schema 是传输形状依据。新预览接口的真实性由后端 SQLite/协议验收验证；浏览器固定数据只用于可重现视觉，不能证明真实外部基础设施健康。

## 9. 验证计划

全量 AC 台账位于主仓 `artifacts/migration-audit/`；计划、代码审查、实际测试与视觉审查分别标注。不得仅因存在截图或测试名就判定全部 AC 实跑通过。

## 9.1 功能验收

按 CRD、AUTH 的 Given/When/Then 执行，断言用户可见结果、请求次数与真实副作用；覆盖取消、失败、重试和竞争。

## 9.2 关键链路

生产构建启动后使用 `web/scripts/check-design-*-v2.mjs`，隔离 HTTP/WebSocket 数据；暗/亮主题及1440/1024/390宽度记录页面错误、溢出与截图。

## 9.3 证据与缺口

每稿 runner manifest 记录来源、夹具、动作与实跑结果；失败必须修正代码或夹具后重跑，不能改成通过。真机条件另行登记，不能由隔离浏览器替代。

## 9.4 产品裁决

依本仓完整领域规格与 open-questions 的已选决定实现；明确 superseded/deferred 的条目保留理由，不算待迁移功能。

## 10. Git 表单与回程

useGitCredentialManager 管理空 secret 表单、真实仓库测试目标、删除确认和克隆回程。StrictMode 重挂载不丢回程；离开凭证路由清理；目标从项目 DTO 读取而非按项目名查另一仓库。
