## 3. 当前结构

AppFrame承载侧栏、顶栏和横幅；工作台主区为项目总览、交互终端或无头输出。SettingsLayout承载凭证、镜像和系统页面。AppDialog/DialogSections统一浮层结构，当前生产container/hook负责查询和命令，view只接props。

## 4. 跨页复用

AuthGateContainer/Panel复用于新任务、凭证卡和初始化；SharedProxyConfigForm复用于检测与设置；EnvVarEditor用于镜像运行参数；新建任务没有任务级环境覆盖字段。复用组件各处使用同一契约与语义token，避免标题、取消行为和错误映射分叉。

## 5. 验收

[12](../12-前端测试体系.md)定义新版独立组件验收与生产浏览器；[16](../16-前端链路验证体系.md)定义到实际后端的链路。验收映射与运行报告分别记录代码审查、实际执行及未执行条件。

## 6. 契约

端点、错误码和wire协议见[10](../../shared/10-接口契约与类型共享.md)，前端消费生成类型。浏览器fixture仅用于重现状态；实际事务、注入绑定、资源回收和MCP注册用后端协议/SQLite验收。
