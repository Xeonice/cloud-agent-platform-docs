## 3. 当前结构

AppFrame承载侧栏、顶栏和横幅；工作台主区为项目总览、交互终端或无头输出。SettingsLayout承载凭证、镜像和系统页面。AppDialog/DialogSections统一浮层结构，当前生产container/hook负责查询和命令，view只接props。

## 4. 跨页复用

AuthGateContainer/Panel复用于新任务、凭证卡和初始化；SharedProxyConfigForm复用于检测与设置；EnvVarEditor复用于镜像与任务参数。复用组件各处使用同一契约与语义token，避免标题、取消行为和错误映射分叉。
