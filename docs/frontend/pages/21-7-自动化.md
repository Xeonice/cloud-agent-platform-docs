# F21-7 · 自动化前端实现

本页对应 [产品说明](../../product/pages/21-7-自动化.md)；[AUT 需求](../../product/requirements/AUT.md) 定义全部 AC。组件清单取当前 workspace，验收结果以运行产物为准。

## 1. 页面职责

按规则调度无头任务，说明凭证/镜像/容量阻塞、最终结果、成果保留与删除影响。

## 2. 路由与骨架落点

项目总览中的自动化列表、规则表单与运行详情。使用 AppFrame/SettingsLayout 与 AppDialog；DialogSections 固定头尾，正文独立滚动。

## 3. 组件树

AutomationsPanelContainer、AutomationListView、AutomationDetailView、AutomationFormView、DeleteAutomationConfirmView。Container 编排查询与命令，view 只接 props；wire 使用生成 DTO。

## 4. 状态与数据接入

project automations、automation attention、enable/disable、deletion-preview/DELETE、runs、logs、webhook-test。

后端结果由 Query 持有，选择与临时编辑由 Zustand/组件持有；事件失效相关 query，不使用事件名称本身冒充业务状态。

## 5. 交互实现要点

选择项目/Agent/镜像，编辑指令与调度。并发触发防重入，忙时跳过并记录原因；显式启停规则；删除预览真实列出任务/历史，完成后刷新注意事项。

最终运行状态以进程退出与清理结果决定；通知失败不伪造任务失败；自动任务成果与清理持久化；全局注意事项与规则自身列表保持一致。

## 6. 状态矩阵落地

规则加载、空、错误、暂停、运行、阻塞；历史包含成功、失败、取消、超时、跳过；输出不可读给重试，不展示假空。

未知数据不可转换为零、成功或空集合。颜色取 v2 语义 token，图标为 SVG；控件保持可访问名称和焦点。

## 7. 本页测试设计

组件验收位于 `web/src/acceptance/`，本域场景：automation / project-workflows。真实 container + HTTP 边界验证交互与副作用。Storybook 验证 view 变体；生产构建浏览器验收验证实际页面与布局。

## 8. 依赖与契约

OpenAPI 生成类型与 shared schema 是传输形状依据。新预览接口的真实性由后端 SQLite/协议验收验证；浏览器固定数据只用于可重现视觉，不能证明真实外部基础设施健康。

## 9. 验证计划

本页按对应领域的 Given/When/Then 维护验收映射。计划、代码审查、测试执行与视觉审查分别记录；测试名称或截图存在不能证明全部 AC 实跑。

## 9.1 功能验收

按 AUT 的 Given/When/Then 执行，断言用户可见结果、请求次数与真实副作用；覆盖取消、失败、重试和竞争。

## 9.2 关键链路

Storybook 核对当前视图状态，生产构建与跨仓浏览器验证真实路由和页面装配；暗/亮主题、桌面与窄屏记录错误、溢出、焦点与截图。

## 9.3 证据与缺口

运行报告关联场景、操作、截图与实际结果；需要真实后端的行为另附 API/跨仓证据。未运行的条件明确列出。

## 9.4 产品裁决

依 [当前产品裁决](../../product/requirements/decisions.md) 与对应领域需求实现；superseded/deferred 保留理由，并明确当前适用范围。

## 10. 调度与注意事项

规则表单与运行详情共同消费服务端状态；attention 列表按失败/阻塞来源去重并稳定排序。删除预览显示运行对象和历史，保留成果按后端最终处理结果展示。
