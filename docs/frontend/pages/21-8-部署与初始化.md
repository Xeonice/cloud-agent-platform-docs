# F21-8 · 部署与初始化前端实现

本页对应 [产品说明](../../product/pages/21-8-部署与初始化.md)；[DEP 需求](../../design-v2/gap/product/DEP.md) · [ACC 需求](../../design-v2/gap/product/ACC.md) 定义全部 AC。组件清单取当前 workspace，验收结果以运行产物为准。

## 1. 页面职责

首次进入先判访问口令，再检查初始化。检测真实网络、运行环境与预制镜像，在线/离线出口均明确。

## 2. 路由与骨架落点

启动检查、全屏访问口令门、阻塞初始化向导。使用 AppFrame/SettingsLayout 与 AppDialog；DialogSections 固定头尾，正文独立滚动。

## 3. 组件树

AppBootGate、AccessGateContainer、UnlockFormView、InitWizardContainer、SharedProxyConfigFormView、AuthGateContainer。Container 编排查询与命令，view 只接 props；wire 使用生成 DTO。

## 4. 状态与数据接入

access/unlock、health、system/init-status、init、settings、diagnose 与 preset-image/provision；runtime auth。

后端结果由 Query 持有，选择与临时编辑由 Zustand/组件持有；事件失效相关 query，不使用事件名称本身冒充业务状态。

## 5. 交互实现要点

首次服务启动生成口令仅stdout一次；解锁后重新判断初始化。网络检测读真实结果；代理读取不触发保存；登录使用同一面板；镜像不可用给可执行出口。

默认口令开启，匿名访问不消耗猜测次数；连续错误提交触发锁定；签名会话7天且可重启保持；轮换口令可选失效其他浏览器；显式回环豁免不用转发头。

## 6. 状态矩阵落地

启动检查中/失败/未初始化/已初始化；口令输入/验证中/错误/锁定；在线、部分可达、离线；镜像可下载、下载中、失败、已就绪。

未知数据不可转换为零、成功或空集合。颜色取 v2 语义 token，图标为 SVG；控件保持可访问名称和焦点。

## 7. 本页测试设计

新版验收位于 `web/src/acceptance/`，本域场景：initialization / credential-access。真实 container + HTTP 边界验证交互与副作用；旧单测已退休，不把旧覆盖率当验收。Storybook 验证 view 变体；设计 runner 验证实际页面状态与布局。

## 8. 依赖与契约

OpenAPI 生成类型与 shared schema 是传输形状依据。新预览接口的真实性由后端 SQLite/协议验收验证；浏览器固定数据只用于可重现视觉，不能证明真实外部基础设施健康。

## 9. 验证计划

全量 AC 台账位于主仓 `artifacts/migration-audit/`；计划、代码审查、实际测试与视觉审查分别标注。不得仅因存在截图或测试名就判定全部 AC 实跑通过。

## 9.1 功能验收

按 DEP、ACC 的 Given/When/Then 执行，断言用户可见结果、请求次数与真实副作用；覆盖取消、失败、重试和竞争。

## 9.2 关键链路

生产构建启动后使用 `web/scripts/check-design-*-v2.mjs`，隔离 HTTP/WebSocket 数据；暗/亮主题及1440/1024/390宽度记录页面错误、溢出与截图。

## 9.3 证据与缺口

每稿 runner manifest 记录来源、夹具、动作与实跑结果；失败必须修正代码或夹具后重跑，不能改成通过。真机条件另行登记，不能由隔离浏览器替代。

## 9.4 产品裁决

依本仓完整领域规格与 open-questions 的已选决定实现；明确 superseded/deferred 的条目保留理由，不算待迁移功能。
