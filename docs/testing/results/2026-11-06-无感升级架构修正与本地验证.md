# 无感升级架构修正与本地验证

本记录接续[失败审计](./2026-11-06-无感升级失败审计.md)和[HTML改造报告](./2026-11-06-无感升级审计与改造计划.html)。上一阶段完成失败核对与六阶段改造计划；本轮开始修正正式执行路径、业务交接和发布资格链。以下是未提交工作区的本地验证，未签发正式包、发布或执行新一轮远端切换。

完整无感改造尚未完成。旧实例首次接入、真实大库下的整个写者交接时限、原 Shell／任务连续性与同构故障回退仍未取得通过结论；不能以本轮测试数量、恢复后可访问或未停止 Guest 代替这些结果。

## 1. 已实现的修正

| 范围 | 实际改动 | 对应验证 |
| --- | --- | --- |
| 旧 stop-first 首迁 | 新增执行策略；正式 CLI 在 SQLite 导入／journal／actor 之前拒绝 apply、resume；默认 runtime 也拒绝。plan、prepare、status 和原操作 rollback 保留。只有显式测试 adapter 可验证旧回退算法，配置不能开启例外 | 实际 CLI 零副作用拒绝、真实 SQLite／HTTP 历史回退及不可变原命令回归 |
| 接入可行性预检 | 对实际 Entry 身份、绑定和 epoch 读取并交叉核对；不能用普通 JSON 自称已支持接入。当前仍明确 blocked，不生成接入完成回执 | 实际 HTTP／TCP 的七项局部合同；不是旧系统整体接入资格 |
| prepared 候选 | 提前装配并监听真实业务端口；HTTP／WS gate 保持关闭，未取得 writer 前不跑 Nest 钩子。端口冲突提前失败，listener 关闭即撤销准备身份 | 实际 Nest、TCP、SQLite：无双写、无提前钩子、失败 gate、端口冲突及关闭监听 |
| 交接只读 | quiescing 只允许健康及项目列表／详情；操作名、GET 与路径共同匹配。鉴权、writer epoch、退休 admission 和变更幂等语义保留 | 实际应用 RPC、鉴权与失效 fence 负例；未知 GET／工具／写入不得绕过 |
| 配额启动扫描 | normal／prepared Coordinator 都在实际 ready 后启动受控全量扫描。未释放登记继续计费，unknown 不释放；旧 epoch 迟到响应不借新 epoch 写入，退休取消 queued 并等 active Promise | 真实 SQLite／HTTP 生命周期及原 Owner placement、worker manifest、冷启动等回归 |
| Control 产物 | unsigned staging、实际 tar 内容校验和签名分开；复核树、链接、权限、engine、归档摘要和长度后才读取签名材料。跨 worker 可验证实际归档，旧 build API 保留 | 本地真实文件系统、native SQLite 和临时 Ed25519 测试材料；未读取正式 publisher 私钥 |
| 正式发布链 | 业务 manifest 绑定独立 Control 描述体与归档；资格指纹共同覆盖。正式签名／发布缺 Control、实际签名错误或归档变化均拒绝 | 正式入口及真实签名／tar 合同；不以标签摘要代替签名验证 |
| API／Web 消费端 | 显式共享 Control schema；API 指纹与 JS producer 一致，旧包保持原公式。消费端校验描述体、engine、revision、平台、来源和正式独立 Control 报告；Web 同步内部包契约 | 真实 JS producer→编译后 API verifier 五项合同，含 API/Web schema 字节一致 |
| 完整资格发现／消费 | Playwright 显式发现首迁及独立控制五场景。实际附件必须与通过的原执行、本次业务目标、Control body、engine 一致；缺失、重复、跳过、失败后附件、重试掩盖、清理错误均拒绝 | 测试发现26场景；证据规则负例及五配置实际签名目录检查。发现与合成报告不能算 Native 执行 |

Web 工作台和系统页组件未改变；本轮只同步内部升级包类型，不新增按钮、访问口令、审批或进度字段。仍由实例管理员决定升级时间，CD 只发布经过门禁的产物。

## 3. 回归中发现并处理的问题

- 第一轮完整部署回归有12项生成契约测试调用到 Corepack shim，在禁止联网时取不到 pnpm；修正本轮测试进程的 PATH，使用已有真实 pnpm。另1项旧测试仍期待配置缺失错误，已改为验证新版更早发生的 stop-first 拒绝。原失败日志保留，最终完整回归重新执行通过。
- API 中一项 retained Coordinator 身份正例被实际容量门拒绝。诊断为宿主 free RAM 72,613,888字节，小于 Vitest RSS 232,767,488字节；磁盘、WAL、heap 与身份／完整性通过，生产拒绝正确。该身份协议测试改为显式宿主内存条件，并新增内存不足仍拒绝的负例；没有修改生产预算。单文件10/10通过，实际诊断和修正日志保留。
- 跨仓复核发现 JS producer 已将 Control 纳入指纹，而 API 消费端仍用旧公式，会报 `QUALIFICATION_INPUT_MISMATCH`。新增真实 producer→编译后消费者测试先复现失败，再修正 API 及 Web 共享契约；旧包指纹与新包实际签名分别验证。
- macOS tar 会引入未包含在签名树的 AppleDouble 数据。Control staging 使用不包含扩展属性的归档方式，实际归档内容仍必须逐项等于签名树；没有删除树校验或放宽摘要规则。

## 4. 尚未通过的关口

1. **旧实例首次接入。** [协议 PoC](../../backend/changes/2026-11-06-旧入口首次控制接入协议PoC.md)说明嵌套入口的合法绑定、Web 资源可见性、外层维护委托及会话边界。旧 Installer 正常退出、本地 steps 全 applied 或 pending 为空，都不足以证明所有远程动作与后台恢复结束。现有失败历史必须逐原 operation 对账，不能套用“从未接纳过升级”的空意图快路。
2. **整个写者交接的2秒上界。** 配额和任务恢复已移出关键路径，Owner RPC 与终端检查已改为共享原截止的有界并行。Nest 初始化、其余启动钩子、完整数据与实际网络耗时仍须测量。端口预热、单个启动测试或过时小库样本不能替代实际大库与端到端请求验证。
3. **最终字节的真实 Native。** 首迁、普通升级、控制器重启、业务故障、未知 ACK、10Hz业务读／幂等写、原 PTY／真实 CLI 任务、逐阶段恢复仍须同构实际运行。必须保存相同 Owner／SDK／VMM／Guest／PID及birth、持续序号和唯一用户请求；任何失败或缺项继续阻断正式发布及线上切换。

本轮没有新建远端迁移操作或停止线上 Entry、Coordinator、Owner、Guest；也没有把本地修正标记为线上升级完成。

## 5. 2026-11-07 整体改造增量

上一阶段停在局部端口预热、配额延后和发布资格链修正。本轮继续实施写权交接、旧控制协议撤权与首迁原结果结算；源码仍未提交、未发布，未连接生产。原审计及此前检查记录保留。

| 改造 | 最终实现与失败边界 |
| --- | --- |
| 任务恢复移出交接窗口 | normal／prepared 的恢复在实际 ready 后启动，先接回已知 job，再查询 pending start 原结果；unknown 不重发。queued 可取消，active 原 Promise 参与退休；旧 epoch 迟到工作不能借新 writer 写入 |
| 一个原截止覆盖交接 | 从原 quiesced_at + requestDeadlineMs 取得共同截止，release／adopt／Owner RPC／初始化／continuity／绑定发布共享；重试不延长。迟到初始化或探测不得开放 HTTP／WS gate；listener 关闭、原 writer generation/fence 改变也拒绝 ready |
| 保留完整连续性判据 | 完整 source 检查在旧服务仍可用时先运行；post-release 仍执行完整检查，PTY 限4并发，Owner audit 和资源读取并行。未删资格条件以换速度 |
| Owner 交接 | 同一实例多个保留 Owner 并行执行、汇总全部原结果。部分／未知 release 保持 releasing，不盲目重新 claim 或恢复 source ready；确认释放后才解除原 writer |
| 原 Guest 启动保护 | prepared 角色强制 SANDBOX_RECONCILE_ON_BOOT=false，避免继承配置进行启动孤儿清理 |
| 旧控制 RPC 撤权 | 真实 Nest 边界在内部鉴权后拒绝独立 ledger 模式的旧升级控制及 contract RPC。业务参与 envelope 保留；原可写 legacy 实例保持原恢复协议。历史 Supervisor 的四条变更链通过实际 HTTP 验证副作用前拒绝，原 authority 不变、生命周期调用零 |
| 原操作只读结算 | 读取历史实际 schema、journal、process、authority、retirement 原件和外部 Inspector 观测，逐原操作核结果。pending 为空但独立恢复未终态、故障提交未闭合、未知 dispatch、过期／缺物理来源均阻断；接入预检只接纳实际 collector 产生的观测。结算通过仍不授权接入，不冒充旧 Supervisor 已有全局 drain |
