## 实现核对

- 单一 OCI config label `platform.runtimeVersions` 保存两个 runtime 的精确 SemVer。缺失、坏 JSON、非法或超长单项逐项降级，不改变镜像可用性；注册、预检和重验复用原有元数据请求。
- schema 28→29 只新增 JSON 列；旧行默认 `{}`，镜像历史、active 指针与已有任务保持。新声明按 digest 保存；同 digest 只补缺键，tag 漂移不写旧行。重新验证的响应声明属于 `upstreamDigest`，更新对比的上游声明属于 `upstream.digest`。
- 列表和普通编辑只读写数据库，不新增层下载、Guest、CLI 执行或模型调用。镜像卡、历史、预检、对比、任务候选和已选项使用各自 digest 的声明；CLI 版本可搜索，创建请求继续提交原有真实坐标。
- 两张官方 Dockerfile 从原固定版本 ARG 写标签，构建命令加强为 CLI 输出精确比较。CI 在匿名读取 amd64/arm64 config 时核对 digest、来源提交与两项版本；错误声明不能获得成功发布回执。本轮没有修改 CLI 固定版本。
