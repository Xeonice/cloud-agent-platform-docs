# 镜像 CLI 版本信息 · 独立前后端测试计划

对应 [PRD](../../product/changes/2026-10-17-镜像CLI版本信息.md)、[IMG 需求](../../product/requirements/IMG.md#REQ-IMG-062)、[后端设计](../../backend/changes/2026-10-17-镜像CLI版本元数据.md)、[前端设计](../../frontend/changes/2026-10-17-镜像CLI版本展示.md)。本文件统一验证后端、前端与两者真实边界；执行通过情况另附实际记录，计划本身不表示通过。

## 1. 测试边界

版本信息是与 digest 绑定的构建声明。测试使用固定 OCI manifest/config fixture、fresh SQLite 和真实 HTTP；不需要真实模型凭据，不启动用户 Guest，不执行宿主 CLI 或发起模型请求。官方镜像构建的真实 `--version` 门禁另提供构建证据；不因组件 fixture 通过就声称镜像安装版本已实测。

## 3. 必需场景与数据

1. 官方完整 map；第三方无 label；只报 Codex；单项非法且另一项有效；非法 JSON/数组/null；额外 runtime 键；合法 prerelease/build；script 文本与超长恶意值。
2. 迁移前镜像、JSON null 旧行；重复注册同 digest 回填；原 tag 重推到新 digest；两个版本有不同 map；切回历史、别名编辑、配置继承、禁用/启用后版本不串。
3. 第三方派生镜像继承原 label 的 fixture：界面只能叫构建声明，不能把平台来源比对当作 CLI 实测；任务实测只有所选 runtime 时也不能补另一 CLI。
4. 默认镜像、普通镜像、部分未知镜像；搜索和选择后提交稳定值，provider 不兼容/禁用原因仍保留；旧 API 省略字段可进入页面与创建任务。

## 4. 执行门禁和记录

后端执行解析单测、真实 registry/config 协议测试、fresh SQLite 迁移/持久化/事务回归、HTTP 与类型构建；构建层执行 Dockerfile 真实 `--version` 及 label/发布身份核对。前端执行纯函数/组件验收、类型/构建与 Storybook，并在真实 API 浏览器链路验证保存重载、历史/对比和任务选择。

记录测试命令、代码版本、fixture/digest、实际返回和截图，不保存凭据。区分原型视觉、替身组件、真实协议、真实镜像构建四种证据。未执行的构建或线上发布写未执行；没有真实镜像构建证据时只能声明元数据展示可用，不能声明某镜像实际安装完整性通过。
