## 1. 当前决策

| 决策 | 当前规则 |
| --- | --- |
| 统一架构 | macOS 宿主 → Colima／VZ Linux arm64 → Docker Foundation 与五个独立角色；BoxLite 在 Owner 内通过 KVM 运行 |
| 升级时机 | CD 只发布可信产物，由管理员决定本实例何时升级 |
| 运行连续性 | 平台更新不擅停 Guest；已有任务归原 Owner，页面刷新通过原书签重连 |
| 实例隔离 | 本机与远端各自拥有数据、Owner home、信任根、渠道及升级历史 |
| 来源退役 | 新实例验收后卸载来源服务和自启动项，保留私有备份；文档只描述当前统一模式 |
| CI 边界 | PR 构建与持有发布凭据的基础设施分离；不得通过模板同步或维护结束恢复自动实例 deploy/promote |
