# 运维与发布入口

本机与 `100.73.71.22` 均采用 **macOS 宿主 → Colima VZ 嵌套虚拟化 → Linux arm64 Docker Foundation／五角色**。远端基础迁移、真实业务验收和来源封存退役已完成，访问 http://100.73.71.22:3000；`.11`是基础迁移历史，后续版本及实际组合以[统一部署记录](./统一虚拟化与实例部署.md)和[最近`.20`失败验收](../testing/results/2026-10-19-升级证据开销修复与恢复准备.md)为准，不能从整体版本号推断所有角色已同版。

现行操作入口为 [统一虚拟化与实例部署](./统一虚拟化与实例部署.md)，实际结果见 [迁移验收报告](../testing/results/2026-10-17-统一部署与在线升级验收.md)。**CD 只发布包，实例升级由管理员决定。** 本轮基础迁移不替代后续 CLI 包、跨升级连续性、模型 Agent 或完整故障资格。

## 1. 先读这六条

| # | 运行红线 | 原因 |
| --- | --- | --- |
| 1 | 合并、构建和发布包不触发实例更新；管理员在实例页面明确发起升级 | 实例独立选择升级时机，CD 不切 API／Web、不停止沙箱 |
| 2 | 每次运维显式指定实例 Docker socket 和私有 Docker 配置目录 | 不继承 OrbStack 全局 context 或其他实例的 credential helper |
| 3 | 通过受控 Installer／Supervisor 管理角色及路由；不以 compose up 重建当前角色 | 保留原 Owner、Guest、终端和已确认绑定 |
| 4 | 禁止 volume／image／system prune；清理仅针对核验过归属的资源 | 持久卷、回退产物及用户数据不能依赖偶然挂载状态保留 |
| 5 | 固定三仓提交、包摘要、实例／渠道和信任根，再签名、验证和发布 | 不用重新生成信任根、漂移 latest 或改写输入冒充可升级版本 |
| 6 | 保留失败与 unknown，不改 ready、不重造 Guest、不整卷恢复覆盖新写入 | 恢复必须依据真实身份、唯一写者和已确认路由 |

主仓、API、Web 均为公开仓库，私钥、Cookie、口令和私有 session 不进入提交、日志或 Release。

## 4. 当前架构与开发边界

平台服务统一运行在 Colima Linux 中。Foundation 承载 StableEntry／Supervisor；ControlAPI、Web、StateCoordinator、RuntimeOwner、Installer 分别运行，业务、产物、来源封存与 Foundation 使用独立卷。已有 Guest 保留原 Owner，API／Web 更新不会把 Guest 搬到新进程。

2026-10-20的[目标方案](../product/changes/2026-10-20-独立升级控制与失败恢复.md)将升级控制、账本与基础观察独立于业务包维护，代码与隔离协议验证进行中，尚未部署。本节仍描述已部署结构；首次控制权迁移和底座维护需单独证明影响与原会话重连，实际进展见[实现记录](../testing/results/2026-10-20-独立升级控制实现与资格准备.md)。

本地 `pnpm` 调试、Darwin SDK 和原生 ABI 兼容性验证属于开发支持，见 [CONTRIBUTING](../../CONTRIBUTING.md)。它们不构成另一套平台部署或实例更新方式。容器／KVM smoke 的能力边界见 [BoxLite 验证工具](../../deploy/containers/boxlite-proof/README.md)。

升级后的页面刷新只加载已激活的 Web 并接回原书签，不能代替部署；版本检查、关闭提醒和只读诊断均不启动升级。

## 6. 术语表

| 术语 | 含义 |
| --- | --- |
| Foundation | 实例常驻入口、Supervisor 和持久路由绑定的基础 |
| 五角色 | ControlAPI、Web、StateCoordinator、RuntimeOwner、Installer |
| 已确认版本 | 本实例实际激活并确认的 release，区别于目录中的可安装版本 |
| 版本目录 | 供实例只读发现的签名版本列表，发布不等于安装 |
| 固定信任根 | 本实例核验包／manifest／catalog 的作用域和公钥，不能随候选重新生成 |
| generation | 本实例已确认激活代数，不能借用另一实例或手工修改 |
| Owner assignment | 将已有 Guest 和终端路由到真实持有它们的运行服务 |
| source／business／artifacts 卷 | 一致封存来源、当前业务数据、校验安装产物，各有独立权限和用途 |
| profile | 独立 Colima VM；当前服务 profile 为 `agent-platform-runtime` |
| hostagent | Lima 在宿主上的 VM／网络辅助进程，不能把它重启等同于实例已恢复 |
| CI worker | 构建、测试或发布资产的执行环境，不拥有管理员实例升级意图 |
| 收据 | 绑定实际输入、物理身份、摘要和结果的记录；失败及未执行也须保留 |
| gitlink | 主仓记录的 API／Web 子仓提交，用于冻结跨仓输入 |
| 私有归档 | 不进入公开仓库的历史原文、凭据及操作证据，按实际用途限制权限 |
