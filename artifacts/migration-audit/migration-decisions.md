# 迁移中发现的规格冲突

日期：2026-10-05。以下记录针对源规格内部互斥条款；原稿与原始 SHA 保留不变，当前实现和完整 AC 台账明确记录被替代分支。未把互斥分支写成测试通过。

## 自动化命令的项目范围

[WB 的 REQ-WB-031 / AC-WB-031.2](../../docs/design-v2/gap/product/WB.md#REQ-WB-031) 要求在项目任务中搜索自动化时只有当前项目一条快捷项；[AUT 的 REQ-AUT-001 / AC-AUT-001.3](../../docs/design-v2/gap/product/AUT.md#REQ-AUT-001) 要求任意页逐就绪项目提供具名入口。

采用自动化领域的具体入口要求：任意页逐就绪项目显示「自动化规则 · <项目名>」，每项目一条；带规则数或「还没有规则」。查看其它项目规则不改变原工作台项目/任务，关闭返回原先焦点。AC-WB-031.2 标为 superseded，保留源期望和冲突理由。成果快捷项不涉及这一冲突。

## 成果删除确认的形态

[PRJ 的 REQ-PRJ-053 / AC-PRJ-053.1](../../docs/design-v2/gap/product/PRJ.md#REQ-PRJ-053) 要求同一 dialog 从列表切到删除确认；AC-PRJ-053.3 同时要求删除请求期间其余列表行仍可用，二者无法同时成立。

采用同一 dialog 的确认视图及请求期间 busy 锁定，AC-PRJ-053.3 标为 superseded。取消不发请求，失败留在确认视图可重试，成功回列表。

## 其它已选产品分支

镜像参数继承的互斥分支与访问控制设置页的延期，依据源稿已选 open-questions 决定，完整台账保留各自理由；这些不属于尚待迁移的功能。审计流历史稿中「尚未记录此分类」的状态也保留原稿，但当前五类均有真实生产事件，不伪造不存在的生产状态来制造视觉通过。
